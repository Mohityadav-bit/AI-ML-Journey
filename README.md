# Complete AI/ML

A structured repository documenting my journey of learning **Artificial Intelligence and Machine Learning** from the fundamentals to advanced concepts.

## What This Repository Contains

- 🐍 **Python** — lectures, practice, and assignments
- 📐 **Mathematics** — Linear Algebra, Calculus, Probability & Statistics
- 🔢 **NumPy & Pandas** — data manipulation and analysis
- 📊 **Data Visualization** — Matplotlib, Seaborn & Plotly
- 🔍 **EDA** — Exploratory Data Analysis and Data Cleaning
- 🤖 **Machine Learning** — algorithms, preprocessing, model evaluation and projects
- 🧠 **Deep Learning** — Neural Networks, CNNs, RNNs, LSTMs & Transformers
- 💬 **NLP** — Natural Language Processing and Transformers
- 👁️ **Computer Vision** — OpenCV, CNNs and image-based projects
- ✨ **Generative AI** — LLMs, RAG, Embeddings, Vector Databases and Agents
- 🚀 **Projects** — practical projects applying the concepts learned
